# Storefront

The hosted studio page: `<slug>.<domain>` shows a studio's profile, contact links, artists and Good to know from the Tattoo Drip API, `/artists/<slug>` is one artist, `/request` is the intake form (`/request?artist=<slug>` asks for one artist), and `/deposit#<token>` is a project's deposit page. TanStack Start, React 19, TanStack Query, Tailwind CSS v4.

# Storefront

The hosted studio page: `<slug>.<domain>` shows a studio's profile, contact links, artists and inquiry section from the Tattoo Drip API, and `/artists/<slug>` asks for one artist. TanStack Start, React 19, TanStack Query, Tailwind CSS v4.

# Clients: list, profile and history (TAT-41) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Owners find a client by name or phone, see their projects, inquiries, references and notes on one page, reach them in one tap, and edit their details.

**Architecture:** `ClientService` grows `list`, `findFor`, `findByPhone` and `update` (with `ClientRuleError`); `ProjectService` and `InquiryService` each answer "for this client" reads about their own records; a new owners-only `ClientsController` combines them for three pages (list, profile, edit). The chat-link helper moves into the clients module. The nav gets a Clients tab for owners, and the project and inquiry pages link to the client.

**Tech Stack:** AdonisJS 7, Lucid (PostgreSQL, RLS), VineJS, Luxon, Inertia + React, shadcn/ui, Tuyau `urlFor`, Japa.

**Spec:** `docs/superpowers/specs/2026-10-17-tat-41-clients-design.md`

## Global Constraints

- No migration; no API, SDK or OpenAPI change.
- Owners only: the `/clients` route group uses `role({ allow: ["owner"] })`; artists get a 404 and no Clients tab; the project page's `clientId` prop is null for artists.
- List: live clients, newest first (`created_at` desc, then `id` desc), 25 per page. Search (trimmed, non-empty): the name contains it case-insensitively with `%`, `_` and `\` escaped; or, with at least 3 digits in the search, the phone without its `+` contains those digits.
- Editable: name (required, trimmed, at most 120), phone (required, the existing `phoneNumber` rule, E.164), email (optional, valid, at most 254; empty becomes null), notes (optional, at most 2,000; empty becomes null). An anonymized client is never edited.
- Copy, verbatim: flash "Client updated."; field error on `phone` "Another client already has this number: {name}."; flash "This client's details were deleted and can't be edited."; profile text "This client's details were deleted."; empty states "No clients yet. They appear when an inquiry arrives.", "No clients match "{q}".", "No notes.", "No projects.", "No inquiries."; link labels "WhatsApp", "Viber", "Call", "Edit details", "View client"; tab label "Clients".
- Every query is scoped by `tenant_id`; no module reads another module's tables (the controller combines services). `@inject()` dependencies are value imports with the `// biome-ignore lint/style/useImportType: @inject() reads the class at runtime (decorator metadata); a type-only import breaks injection.` comment.
- Commands run from `apps/platform` unless stated; tests use `PORT=3402`. Don't wrap commands in `sh -c`. `pnpm typecheck` is the authority over editor diagnostics. After route or page changes run `node ace codegen` and commit `.adonisjs/`. ## Review Focus

1. Search input that isn't a plain name: `%`, `_`, `\`, mixed case, a phone typed with spaces or dashes or with/without "+977", fewer than 3 digits, only spaces. Expected: literal matches, no error, no "match everything". (Task 2 tests.)
2. Changing a phone to another live client's number (a field error naming that client, nothing changed), and to the number of a client who was deleted (allowed: a deleted client frees its number). (Tasks 2 and 6 tests.)
3. A client with no projects, inquiries, references, email or notes: the profile shows the empty states and nulls, never broken values. (Task 5 test.)
4. An artist: 404 on every clients route, no Clients tab, and the project page gives them `clientId: null`. (Tasks 4, 5, 6, 7 tests.)
5. Deleted records and other studios: a soft-deleted project or reference image never shows on a profile; another studio's client id is a 404 on every route and changes nothing. (Task 3 tests and the isolation cases.)

```ts
/**
 * Links that reach a client at `phone` (E.164): a chat on WhatsApp or
 * Viber, and a call. WhatsApp can prefill `text`; Viber's chat link takes
 * no text, so staff paste it (the project page's Copy button).
 */
export function chatLinks(
	phone: string,
	text?: string,
): { whatsapp: string; viber: string } {
	const digits = phone.replace(/\D/g, "");
	return {
		whatsapp:
			text === undefined
				? `https://wa.me/${digits}`
				: `https://wa.me/${digits}?text=${encodeURIComponent(text)}`,
		viber: `viber://chat?number=%2B${digits}`,
	};
}

/** A link that starts a phone call to `phone` (E.164). */
export function telLink(phone: string): string {
	return `tel:${phone}`;
}
```

```ts
export const CLIENT_RULE_REASONS = ["phone_taken", "anonymized"] as const;
export type ClientRuleReason = (typeof CLIENT_RULE_REASONS)[number];

const MESSAGES: Record<ClientRuleReason, string> = {
	phone_taken: "Another live client of the tenant has this phone",
	anonymized: "The client's details were deleted; it can't be edited",
};

/**
 * A client rule was broken; `reason` says which. Thrown after the failed
 * savepoint has rolled back. The message is for developers; show your own
 * to the user.
 */
export class ClientRuleError extends Error {
	constructor(readonly reason: ClientRuleReason) {
		super(MESSAGES[reason]);
		this.name = "ClientRuleError";
	}
}
```

```ts
import { ClientRuleError } from "#modules/clients/errors";
import Client from "#modules/clients/models/client";
import type Tenant from "#modules/tenancy/models/tenant";
import { withTransaction } from "#services/db_context";
import { isUniqueViolation } from "#services/db_errors";

type TenantRef = Pick<Tenant, "id">;

/** Clients per page on the clients list. */
export const CLIENTS_PER_PAGE = 25;

/** The partial unique index: one live client per phone per tenant. */
const PHONE_INDEX = "clients_tenant_phone_live_unique";

export type ClientPage = {
	clients: Client[];
	total: number;
	lastPage: number;
};

/** What an owner can edit on a client (the phone already in E.164). */
export type ClientInput = {
	name: string;
	phone: string;
	email: string | null;
	notes: string | null;
};

/**
 * The way to find, list and edit a tenant's clients (TAT-37, TAT-41).
 * Every call is scoped to the tenant; the clients pages are owners only.
 * Intake (TAT-51) matches by phone with `findByPhone` and never changes a
 * client: only an owner's edit does.
 */
export default class ClientService {
	/** The tenant's live client with this id, or null. */
	async find(tenant: TenantRef, id: string): Promise<Client | null> {
		return Client.query().where("tenant_id", tenant.id).where("id", id).first();
	}

	/**
	 * The tenant's live clients among `ids`, in no particular order (a page
	 * of the projects list looks up its client names in one query).
	 */
	async findMany(tenant: TenantRef, ids: string[]): Promise<Client[]> {
		if (ids.length === 0) return [];
		return Client.query().where("tenant_id", tenant.id).whereIn("id", ids);
	}

	/** The tenant's live client with this id, else E_ROW_NOT_FOUND (a 404). */
	async findFor(tenant: TenantRef, id: string): Promise<Client> {
		return Client.query()
			.where("tenant_id", tenant.id)
			.where("id", id)
			.firstOrFail();
	}

	/** The tenant's live client with this E.164 phone, or null. */
	async findByPhone(tenant: TenantRef, phone: string): Promise<Client | null> {
		return Client.query()
			.where("tenant_id", tenant.id)
			.where("phone", phone)
			.first();
	}

	/**
	 * Live clients, newest first, 25 per page. A search matches part of the
	 * name in any case (literally: `%` and `_` are not wildcards) or, with
	 * at least 3 digits in it, part of the phone's digits however the
	 * number was typed ("981-234", "+977 981…").
	 */
	async list(
		tenant: TenantRef,
		{ search, page }: { search: string; page: number },
	): Promise<ClientPage> {
		const query = Client.query().where("tenant_id", tenant.id);
		const term = search.trim();
		if (term) {
			const digits = term.replace(/\D/g, "");
			// Grouped, so the soft-delete filter appended later still applies to
			// both branches.
			query.where((group) => {
				group.whereRaw("name ilike ? escape '\\'", [`%${escapeLike(term)}%`]);
				if (digits.length >= 3) {
					group.orWhereRaw("replace(phone, '+', '') like ?", [`%${digits}%`]);
				}
			});
		}
		const result = await query
			.orderBy("created_at", "desc")
			.orderBy("id", "desc")
			.paginate(page, CLIENTS_PER_PAGE);
		return {
			clients: result.all(),
			total: result.total,
			lastPage: result.lastPage,
		};
	}

	/**
	 * Saves an owner's edit, under the client's row lock. An anonymized
	 * client (TAT-42) is refused ("anonymized"); a phone another live client
	 * of the tenant has is refused ("phone_taken") by the unique index,
	 * caught after the savepoint rolled back. Empty email and notes become
	 * null.
	 */
	async update(
		tenant: TenantRef,
		client: Client,
		input: ClientInput,
	): Promise<Client> {
		if (client.tenantId !== tenant.id) {
			throw new Error(`Client ${client.id} belongs to another tenant`);
		}
		try {
			return await withTransaction(async (trx) => {
				const live = await Client.query({ client: trx })
					.where("tenant_id", tenant.id)
					.where("id", client.id)
					.forUpdate()
					.firstOrFail();
				if (live.anonymizedAt) throw new ClientRuleError("anonymized");
				live.merge({
					name: input.name,
					phone: input.phone,
					email: input.email || null,
					notes: input.notes || null,
				});
				await live.save();
				return live;
			});
		} catch (error) {
			if (isUniqueViolation(error, PHONE_INDEX)) {
				throw new ClientRuleError("phone_taken");
			}
			throw error;
		}
	}
}

/** Escapes LIKE's wildcards and its escape character. */
function escapeLike(value: string): string {
	return value.replace(/[\\%_]/g, (char) => `\\${char}`);
}
```

```ts
import { inject } from "@adonisjs/core";
import type { HttpContext } from "@adonisjs/core/http";
import { DateTime } from "luxon";
import { tenantContext } from "#middleware/tenant_middleware";
// biome-ignore lint/style/useImportType: @inject() reads the class at runtime (decorator metadata); a type-only import breaks injection.
import ClientService from "#modules/clients/services/client_service";
// biome-ignore lint/style/useImportType: @inject() reads the class at runtime (decorator metadata); a type-only import breaks injection.
import InquiryService from "#modules/inquiries/services/inquiry_service";
import { daysAgoText } from "#modules/projects/contact";
// biome-ignore lint/style/useImportType: @inject() reads the class at runtime (decorator metadata); a type-only import breaks injection.
import ProjectService from "#modules/projects/services/project_service";

/**
 * The clients pages (TAT-41): owners only (the route group's role check).
 * Every :id loads through ClientService.findFor, so another tenant's or a
 * deleted client is a 404. The history comes from the projects and
 * inquiries services; this controller reads no table itself.
 */
@inject()
export default class ClientsController {
	constructor(
		private clients: ClientService,
		private projects: ProjectService,
		private inquiries: InquiryService,
	) {}

	async index(ctx: HttpContext) {
		const { tenant } = tenantContext(ctx);
		const query = ctx.request.qs();
		const search = typeof query.q === "string" ? query.q.trim() : "";
		const page = Math.max(1, Number.parseInt(String(query.page ?? 1), 10) || 1);

		const { clients, total, lastPage } = await this.clients.list(tenant, {
			search,
			page,
		});
		const ids = clients.map(({ id }) => id);
		const counts = await this.projects.countsForClients(tenant, ids);
		const projectChanges = await this.projects.lastChangeForClients(tenant, ids);
		const inquiryTimes = await this.inquiries.latestForClients(tenant, ids);

		return ctx.inertia.render("clients/index", {
			search,
			clients: clients.map((client) => ({
				id: client.id,
				name: client.name,
				phone: client.phone,
				projects: counts.get(client.id) ?? 0,
				lastActivityText: daysAgoText(
					latest([
						client.createdAt,
						projectChanges.get(client.id),
						inquiryTimes.get(client.id),
					]),
					tenant.timezone,
				),
			})),
			page: { current: page, last: lastPage, total },
		});
	}
}

/** The latest of these times (the first one is always set). */
function latest(times: [DateTime, ...(DateTime | undefined)[]]): DateTime {
	return times.reduce<DateTime>(
		(max, time) => (time && time > max ? time : max),
		times[0],
	);
}
```

```ts
	async update(ctx: HttpContext) {
		const { tenant } = tenantContext(ctx);
		const client = await this.clients.findFor(tenant, ctx.params.id);
		const input = await ctx.request.validateUsing(updateClientValidator);
		try {
			await this.clients.update(tenant, client, input);
		} catch (error) {
			if (!(error instanceof ClientRuleError)) throw error;

				},
			]);
		}
		ctx.session.flash("success", "Client updated.");
		return ctx.response
```
